# SVC scratch results

This directory is an evidence package generated by `run_research_suite.py`, `render_results.py`, and the optional `reference_comparison.py`. `raw/` contains machine-readable logs, `tables/` contains a summary CSV, and `figures/` contains plots rendered from the final raw suite log. No FNEWS model, split, checkpoint, or raw dataset was changed.

Each completed suite record includes seed, timestamp, dataset identifier, train/validation/test sizes, configuration, timings, peak `tracemalloc` usage, predictions, metrics, and solver diagnostics. The bounded Fakeddit result is stored separately because it is a source-taxonomy experiment, not a synthetic benchmark.
